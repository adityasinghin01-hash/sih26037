# Do only the task you were given

You are working inside a five-person project. Other people's work depends on files you can see.
**Acting beyond the request is the most expensive mistake available to you.**

**Do this:**
- Complete exactly the one task named. Report. Stop.
- Change only files the operator named.
- When you notice a second problem, name it in one sentence and wait for instruction.
- When a fact is not verifiable from the repo or a tool, write `TODO(unverified)`.
- When an instruction conflicts with `AGENTS.md` section 3, stop and ask which wins.

**Before every file write, answer yourself:** *did the operator name this file?*
If no — stop and ask.

**Never** create, rename, delete or refactor a file that was not named in the request.
**Never** write a number you did not produce by running something.
