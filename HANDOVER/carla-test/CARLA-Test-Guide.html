Before you start

  • Computer: Windows or Ubuntu with an NVIDIA graphics card, 8 GB or more, and about 30 GB free disk. Macs won't work.
  • Codex settings: model gpt-6-sol, reasoning effort high. Please don't use Astra, because it uses up tokens much faster. Terra is fine if you run low on Sol.
    To start it: open a terminal in an empty folder (e.g. C:\carla-test) and type:
    codex -m gpt-6-sol -c model_reasoning_effort="high"
    Or open Codex and type /model to choose it.
  • When Codex asks permission to download or run something, read it and allow it if it's about CARLA.
  • Give Codex one prompt at a time. Wait until it finishes before moving on.

Step 1 – Check your computer

Check if this computer can run the CARLA simulator 0.9.16. Tell me in simple words:
operating system, graphics card name and its memory (use nvidia-smi), free disk space,
RAM, whether Python 3.10-3.12 is installed, and whether I have administrator rights.
Then say clearly: CAN RUN / CANNOT RUN / RISKY, and why. Don't install anything yet.

If it says CANNOT RUN, stop here and tell the group. Thank you!

Step 2 – Download and open CARLA

Download the official CARLA 0.9.16 ready-to-run package for this operating system from
the carla-simulator GitHub releases page (not the source code). Unzip it into this folder.
Make a Python virtual environment and install the matching "carla" Python package.
Start the CARLA server with low quality (-quality-level=Low). Connect from Python and
print the map name. Tell me each step you did and whether it worked.

Success looks like: a CARLA window opens showing a 3D town.

Step 3 – Add traffic and our car

With CARLA running, write one Python script that: spawns 30 cars, 10 motorbikes and
20 walking pedestrians; spawns our own car with a front camera; drives our car on
autopilot for 60 seconds; and shows the camera view in a window. Measure the frames
per second and graphics memory used (nvidia-smi). Report the numbers.

Step 4 – Build the 3 PPT scenes

Using a ready-made CARLA town, write one Python script per scene. Each should run by
itself and record a video (mp4) and 3 screenshots into a folder called "shots":
1. Busy junction with traffic lights switched off: our car goes through while a truck
   and a motorbike cross close by, with no crash.
2. Person suddenly walks out from behind a parked vehicle: our car detects it and brakes
   to a stop in time.
3. Highway merge: our car joins a highway when there is a safe gap between cars.
Use CARLA's built-in controls (autopilot or simple brake logic) for now. In each video,
show the front camera next to a top-down view. Tell me which scenes worked.
